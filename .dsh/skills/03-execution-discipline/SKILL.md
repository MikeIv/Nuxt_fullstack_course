# Execute

**До правок:** релевантные файлы; эталоны (`90`); `nuxt-template.mdc`; `brief.md` / план волны; при UI — кадр Figma из `90`.

**Правки:** одна логическая задача; минимальный diff; без commit/push без просьбы.

**Порядок:** типы/shared/composables → UI → стили (`--fs-*`, mobile-first, миксины `from-*`, не сырой `max-width`). **L+:** контракты в Discuss (`06` п.3).

**Отчёт волны (bullets):** Сделано · Файлы (path — зачем) · Проверено · Дальше.

**Застрял:** не угадывать 4+ раз — гипотеза, проверка, блокер.
