# Figma: доступ к макету

MCP-сервер Figma работает только в Cursor. В DS Harness макет читается REST API по
токену — по тем же `fileKey` и `nodeId`, что указаны в `90-project-context.mdc`.

| Инструмент | Как читает макет                                                                        |
| ---------- | --------------------------------------------------------------------------------------- |
| Cursor     | MCP **figma**: **1×** `get_design_context` на primary node + `get_screenshot` для остальных брейкпоинтов |
| DS Harness | `node scripts/figma.mjs nodes\|png <nodeId>` — REST API по токену                        |

Почему в DS Harness не MCP: удалённый `mcp.figma.com/mcp` требует OAuth, а клиент DS
Harness умеет только `url` + `headers`; локального Dev Mode сервера в актуальных сборках
Figma нет. Локальный путь не искать заново.

## Хелпер

```bash
node scripts/figma.mjs meta                    # fileKey, имя файла, дата правки, страницы
node scripts/figma.mjs nodes 148:15227         # сводка узла, дерево, тексты и шрифты
node scripts/figma.mjs nodes 148:15227 --json  # + дамп в .planning/figma/<id>.json
node scripts/figma.mjs png 148:15227           # рендер → .planning/figma/<id>@2x.png
```

- `fileKey` скрипт берёт из `90-project-context.mdc` (строка `- **fileKey:** …`) и не
  дублирует его; переопределение — `--key` или `FIGMA_FILE_KEY`.
- Токен: переменная окружения `FIGMA_TOKEN` (экспорт в шелле — `.env` скрипт не читает) или
  локальный файл `~/.dsh/figma-pat.txt`. В чат, код и коммиты не попадает.
- `--json` отдаёт дерево и тексты; `--paths` добавляет геометрию путей и делает дамп в
  разы тяжелее — нужен редко.
- Если `scripts/figma.mjs` в проекте ещё нет — взять из шаблона-источника (скрипт без
  зависимостей) и добавить в `package.json` шорткаты `figma:meta` / `figma:nodes` /
  `figma:png`.

## Правила работы

- Один кадр (секция) за волну, только по запросу; весь файл сразу не верстать.
- Ключ брать только из `90`: у файла бывают живые копии с одинаковым именем — перед
  вёрсткой сверять `meta` (дата правки, число страниц).
- CSS Figma не копировать как есть: адаптировать под `--fs-*`, mobile-first и
  брейкпоинты проекта.
- Лимиты REST — порядка 20 запросов в минуту на файл, у изображений строже. При `429`
  сказать прямо и подождать, а не ретраить молча; `GET /v1/me` может отдавать `403` —
  чтению файлов это не мешает.

## Ограничения DS Harness

- Исходящая сеть из оболочки закрыта: обращение к Figma требует расширения доступа —
  это ожидаемо, а не сбой.
- Запись в `.planning/` из ограниченной оболочки тоже может просить расширение.
- MCP-инструментов Figma в DS Harness нет: не выдумывать их вызовы и не выдавать
  отсутствие данных за «пустой макет».
