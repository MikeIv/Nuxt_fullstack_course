# Plan

**L/XL:** `.planning/` (`PROJECT.md`, `brief.md`, `plan.md`, `state.md`). **M:** план в чате или короткий `plan.md`.

**Волна** = 1–3 задачи, узкий scope. Между волнами — `state.md` + краткий итог (`/wave-done`).

**Порядок (Nuxt):** типы/API → composables → страницы; layout/shell → pages; SCSS-токены → компоненты. Макет Figma — **один кадр/секция за волну**, не весь файл.

План **L+** — показать до массовых правок. Scope — только после «да».
